下拉选项说明

彩票名称

后台和前台展示的彩票名称

文本输入框，必填，2-30个字符

如：重庆时时彩、香港六合彩、北京赛车PK10

彩票编码

彩票唯一识别编码

英文/数字/下划线，必填，2-20位，创建后不可修改

如：SSC、HK6、PK10；用于接口、订单、期号、玩法关联

所属类型

彩票所属业务分类

下拉单选，必填

数字彩票 / 活动抽奖 / 奖池玩法 / 即开玩法 / 夺宝玩法

数字彩票：时时彩、六合彩、PK10；活动抽奖：大转盘；奖池玩法：奖池分配；即开玩法：刮刮乐；夺宝玩法：一元夺宝

彩票图标

前台和后台展示图标

图片上传，必填，建议 200×200px，支持 jpg/png/webp

状态

控制该彩票是否可用

单选按钮，必填

启用 / 停用

启用：前台可展示和投注；停用：前台不可投注，后台保留数据

上线时间

彩票开始生效时间

日期时间选择器，格式 YYYY-MM-DD HH:mm:ss

到达该时间后才允许前台展示或投注

支持终端

控制哪些端可以展示和投注

复选框，建议多选

H5 / APP / PC

H5：手机网页；APP：原生应用；PC：电脑网页

支持币种

控制该彩票可使用的投注币种

复选框

CNY / USDT / MYR / THB / PHP

CNY：人民币；USDT：泰达币；MYR：马币；THB：泰铢；PHP：菲律宾比索

开奖地区

彩票官方开奖归属地区

下拉单选，必填

中国大陆 / 香港 / 澳门 / 台湾 / 新加坡 / 马来西亚 / 菲律宾 / 泰国 / 其他

用于绑定开奖时区、开奖源、休市规则；

时区

用于期号日期、开售、封盘、开奖时间计算

下拉单选，必填

UTC+08:00 / UTC+07:00 / UTC+09:00 / 自定义

UTC+08:00：北京/香港/马来西亚；UTC+07:00：泰国；UTC+09:00：日本/韩国

API标识

对外接口或前端调用标识

文本输入，英文小写+下划线，必输

如：ssc_lottery、hk6_lottery，用于前端接口识别
