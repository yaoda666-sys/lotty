下拉选项说明

是否启用选号校验

提交投注前是否校验选号是否合法

开关，必填

开启 / 关闭

开启：未满足选号规则不可提交；关闭：不建议正式环境使用

号码范围校验

是否校验号码是否超出范围

开关

开启 / 关闭

开启：例如 0-9 之外的号码不允许

位置数量校验

是否校验投注位置数量是否满足要求

开关

开启 / 关闭

开启：五星直选必须选五个位置

每位选择数量校验

是否校验每个位置最少/最多选择数

开关

开启 / 关闭

开启：每位至少1个，最多不超过配置

重复号码校验

是否校验号码是否重复

下拉单选

不校验 / 禁止重复 / 允许重复但提示

不校验：不处理重复；禁止重复：重复不可提交；允许重复但提示：仅提示用户

顺序合法性校验

是否校验号码顺序规则

开关

开启 / 关闭

开启：需要顺序匹配的玩法必须保留位置顺序

注数上限校验

是否限制最大注数

开关

开启 / 关闭

开启：超过最大注数禁止提交

金额上限校验

是否校验投注金额上限

开关

开启 / 关闭

开启：超过玩法或彩票限额不可提交

倍数范围校验

是否校验投注倍数范围

开关

开启 / 关闭

开启：倍数必须在最小/最大倍数内

封盘时间校验

是否校验当前期是否已封盘

开关

开启 / 关闭

开启：封盘后不可投注

期号状态校验

是否校验当前期号状态

多选框

待开始 / 售卖中 / 已封盘 / 开奖中 / 已开奖 / 已取消

售卖中：允许投注；其他状态通常不允许投注

用户状态校验

是否校验用户是否可投注

多选框

正常 / 冻结登录 / 限制投注 / 黑名单 / 风控关注

正常：可投注；限制投注/黑名单：不可投注；风控关注：可触发额外审核

异常处理方式

校验失败后系统如何处理

下拉单选

阻止提交 / 提示后允许 / 转人工审核 / 标记异常订单

阻止提交：最常用；提示后允许：风险较高；转人工审核：特殊玩法；标记异常订单：后台处理

是否记录校验日志

是否保存校验失败记录

开关

开启 / 关闭

开启：便于排查异常投注
