下拉选项说明

类型名称

玩法类型的中文名称

文本输入框，必填，2-20个字符

例如：数字直选型、数字组选型、大小单双型，默认情况下不允许修改

类型编码

系统识别该玩法类型的唯一编码

英文大写、数字、下划线，必填，2-30位；创建后建议不可修改

例如：DIGIT_DIRECT、DIGIT_GROUP、BIG_SMALL；用于规则引擎识别；编辑不允许修改

类型简称

列表或前台展示的短名称

文本输入框，选填，1-10字

例如：直选型、组选型、和值型

上级类型

当前玩法类型所属的父级类型

下拉单选，必输

无上级类型 / 数字类 / 属性类 / 活动类 / 奖池类 / 即开类 / 自定义上级类型

无上级类型：作为一级类型；数字类：时时彩、PK10等数字玩法；属性类：生肖、色波；活动类：抽奖、大转盘；奖池类：奖池分配；即开类：刮刮乐

类型描述

对玩法类型的简要说明

多行文本，选填，0-200字

例如：按开奖顺序和位置选择号码，全部位置按顺序一致即中奖

状态

控制该玩法类型是否可被使用

单选按钮，必填

启用 / 停用

启用：新增玩法时可选择；停用：不可再被新玩法选择，已有玩法可保留历史规则

排序

控制玩法类型列表展示顺序

数字输入框，必填，正整数

数值越小越靠前

适用范围

控制该类型可用于哪些业务场景

下拉单选/多选

数字彩票 / 活动抽奖 / 奖池玩法 / 即开玩法 / 一元夺宝玩法 / 多场景通用

数字彩票：时时彩、PK10、六合彩；活动抽奖：转盘、抽奖；奖池玩法：累计奖池；即开玩法：即时开奖；一元夺宝玩法：夺宝类；多场景通用：可跨多个业务使用

主要获取彩票类型配置参数；
