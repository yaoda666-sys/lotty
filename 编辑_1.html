下拉选项说明

分类名称

玩法分类的中文名称，后台和前台都可使用

文本输入框，必填，2-20个字符

例如：数字直选、数字组选、大小单双、和值、生肖、色波

分类编码

系统识别该玩法分类的唯一编码

英文大写、数字、下划线，必填，2-30位；创建后建议不可修改

例如：DIGIT_DIRECT、DIGIT_GROUP、BIG_SMALL；用于系统配置、接口识别、玩法归类

分类描述

对当前玩法分类的简要说明

多行文本，选填，0-200字

例如：对应开奖号码每个位置进行号码选择，按顺序全部命中即中奖

状态

控制该玩法分类是否可使用

单选按钮，必填

启用 / 停用

启用：该分类可被玩法选择，前台可展示；停用：该分类不可被新玩法选择，前台不展示

排序

控制后台列表和前台分类展示顺序

数字输入框，必填，正整数

数值越小越靠前，例如 1 排在 2 前面

上级分类

当前分类所属的父级分类

下拉单选

基础玩法 / 属性玩法 / 特殊玩法 / 自定义上级分类 / 无上级分类

基础玩法：直选、组选、和值等基础规则类；属性玩法：生肖、色波等属性类；特殊玩法：即开、奖池、一元夺宝等；无上级分类：作为一级分类

分类层级

系统根据上级分类自动计算的层级

只读字段

一级分类 / 二级分类 / 三级分类

一级分类：顶级分类；二级分类：挂在一级分类下；三级分类：更深层级，建议少用，避免前台结构复杂；一级分类一般为：基础玩法、属性玩法、特殊玩法；二级分类是具体的玩法归类，如数字直选、数字组选、大小单双、和值、生效和色波；三级分类：具体的玩法挂在二级分类下面，如五星直选、前三直选、特码和红波

是否展示在前台

控制该分类是否在用户端展示

开关

开启 / 关闭

开启：前台玩法分类区域展示；关闭：前台不展示该分类及其下玩法，但后台仍可维护

前台显示名称

前台展示给用户看的分类名称

文本输入框，选填，1-10个字符

可与后台分类名称不同，例如后台“数字直选”，前台显示“直选类”

适用彩票

控制该分类可以用于哪些彩票

单选按钮，必填

全部彩票 / 指定彩票

全部彩票：所有彩票都可以使用该分类；指定彩票：只允许选择的彩票使用该分类

指定彩票

当“适用彩票=指定彩票”时出现

下拉多选

彩票列表动态读取

例如：重庆时时彩、香港六合彩、北京赛车PK10；只有被选中的彩票才能关联该玩法分类

支持玩法类型

控制哪些玩法类型可以归类到该分类下

多选框，必填

数字直选型 / 数字组选型 / 组合选号型 / 大小单双型 / 和值型 / 区间命中型 / 属性型 / 固定奖项型 / 概率抽奖型 / 奖池分配型 / 一元夺宝型 / 即开型 / 排名型 / 复合混合型 / 其他类型

数字直选型：按位置精准命中；数字组选型：号码组合命中，不严格按顺序；组合选号型：多个号码组合成注；大小单双型：判断大小、单双；和值型：按开奖号码和值判断；区间命中型：命中指定区间；属性型：生肖、色波等；固定奖项型：固定奖品或固定金额；概率抽奖型：按概率抽奖；奖池分配型：按奖池比例分配；一元夺宝型：按夺宝规则开奖；即开型：即开即中；排名型：PK10、赛车排名类；复合混合型：组合多种规则；其他类型：暂未归入标准模板的玩法
