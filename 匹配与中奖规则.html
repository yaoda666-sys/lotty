下拉选项说明

匹配方式

定义用户投注内容与开奖结果如何比较；默认值获取中奖模版

下拉单选，必填

完全匹配 / 顺序匹配 / 无序匹配 / 和值匹配 / 属性匹配 / 区间匹配 / 排名匹配 / 概率命中 / 奖池分配 / 即开结果 / 复合匹配 / 自定义规则

完全匹配：投注号码与开奖号码完全一致；顺序匹配：号码和位置顺序必须一致；无序匹配：号码相同即可，不要求顺序；和值匹配：按开奖号码和值判断；属性匹配：按生肖、色波、大小、单双等属性判断；区间匹配：开奖号码落在指定区间即命中；排名匹配：按名次/排名结果判断；概率命中：按概率抽奖结果判断；奖池分配：按奖池规则分配奖金；即开结果：刮开或即时结果判断；复合匹配：多个条件组合判断；自定义规则：通过脚本或公式判断

中奖条件

描述该玩法类型满足中奖的核心条件

多行文本，必填，0-200字

例如：所选所有位置与开奖号码完全一致即为中奖

和局处理

出现和局或特殊平局结果时如何处理

下拉单选，必填

不适用 / 判定和局 / 退还本金 / 按和局赔率派奖 / 判定未中奖 / 自定义

不适用：该玩法没有和局；判定和局：订单状态为和；退还本金：退回投注金额；按和局赔率派奖：按特殊赔率结算；判定未中奖：直接不中奖

未中奖处理

未满足中奖条件时如何处理

下拉单选，必填

不中奖 / 退还本金 / 进入安慰奖 / 转入待复核 / 自定义处理

不中奖：订单判定为未中奖；退还本金：退回投注金额；进入安慰奖：可用于活动玩法；转入待复核：人工审核；自定义处理：按特殊规则执行

是否复核中奖

中奖结果是否需要人工复核

单选按钮，必填

否 / 是

否：系统自动判定；是：中奖后进入人工复核流程

结果输出格式

中奖结果或开奖结果对外展示格式

下拉单选，必填

纯数字 / 空格分隔 / 逗号分隔 / 竖线分隔 / 号码+特别号 / 排名格式 / JSON格式 / 图文卡片 / 自定义格式

纯数字：如12345；空格分隔：1 2 3 4 5；逗号分隔：1,2,3,4,5；竖线分隔：1|2|3；号码+特别号：六合彩类；排名格式：PK10名次；JSON格式：接口结构化返回；图文卡片：即开/抽奖展示
